# 💼 VisionPDV

**VisionPDV** é um sistema PDV (Ponto de Venda) moderno e escalável, ideal para micro e pequenas empresas. O projeto será desenvolvido como um SaaS, com foco em simplicidade, performance e usabilidade.

> 🛠️ Projeto em fase de **documentação e planejamento técnico**.  
> Este repositório será atualizado continuamente durante o desenvolvimento.

## 🎯 Objetivo do Projeto

Criar uma solução robusta e intuitiva para controle de vendas, estoque, caixa, e relatórios financeiros em tempo real, acessível via navegador.

---

## 🧪 Tecnologias propostas

- **HTML5** + **Tailwind CSS** (UI)  
- **JavaScript** (lógica de negócio)  
- Futuro: **Node.js** + **PostgreSQL** para API SaaS e persistência

---

## 📋 Módulos planejados

- [ ] Cadastro de produtos com código de barras
- [ ] Movimentação de estoque
- [ ] Tela de vendas com carrinho e fechamento
- [ ] Comissões por vendedor
- [ ] Abertura e fechamento de caixa
- [ ] Relatórios de vendas e estoque
- [ ] Multiusuário e multiempresa (SaaS)
